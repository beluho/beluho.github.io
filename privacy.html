Privacy policy

Last updated: 27 October 2026

gmail-multi-mcp is a personal, self-hosted tool. It is installed and run by its owner on their own computer. It has no servers, no database and no users other than its owner.

What data it accesses

With the owner's consent through Google sign-in, the tool reads, searches, labels, drafts and sends email in the Gmail accounts the owner connects. It only acts when the owner asks it to.

Where data goes

Email content is fetched directly from Google's Gmail API to the owner's computer and shown to the owner's own AI assistant session. Google OAuth tokens are stored only in a local file on that computer. Nothing is sent to any third party by this tool, and nothing is stored anywhere other than the owner's own machine.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time by deleting the local token files or by removing the app under Google account permissions.
